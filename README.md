Generated by `@pivotly/plugin` 0.0.0.

Each directory sets up one AI client completely: its skills **and** the Pivotly MCP
server. Nothing here needs editing.

This build is pinned to `http://localhost:8080/mcp` and sends no credential, so there is
nothing to set. It only works against that server — regenerate for anywhere else.

```bash
claude plugin marketplace add .
claude plugin install pivotly
```

## Verify these paths before relying on them

These MCP config paths are a best reading of each client, not confirmed against a
running install. If one is wrong the client ignores the file: the skills still work,
the tools do not appear, and nothing reports an error.

- **OpenAI Codex** — `codex/.codex/config.toml`
- **GitHub Copilot** — `copilot/.vscode/mcp.json`
- **Windsurf** — `windsurf/.windsurf/mcp_config.json`

## What is in `bundles.json`

The build inventory: this generator and its version, a catalog of every skill in the
library, and per package its files with a `sha256` each plus a digest. Two builds of the
same sources produce an identical inventory, so a diff of this file is a real change.
