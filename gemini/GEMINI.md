# Pivotly

This extension adds the Pivotly MCP server and the commands below.

## Commands

- `/pivotly:math-add` — Add two or more numbers and report the sum together with its operands.
- `/pivotly:math-divide` — Divide numbers and report the quotient, refusing division by zero.
- `/pivotly:math-multiply` — Multiply numbers and report the product, flagging any loss of precision.
- `/pivotly:math-subtract` — Subtract numbers and report the difference, stating which operand came first.
- `/pivotly:greeting` — Greet a person by name, matching the tone and language of the conversation.

Each command carries its own procedure and pitfalls; invoke one rather than guessing.
